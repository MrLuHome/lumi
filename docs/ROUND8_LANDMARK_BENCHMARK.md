# ROUND 8 — 关键点质量基准

- 日期：2026-11-21
- 机器：MacBook / Apple M4 / 16 GB / macOS（Apple Silicon），debug 测试构建（`cargo test` 默认 profile）
- 可重复性：`cd src-tauri && cargo test --test round8_benchmark -- --ignored --nocapture`
- 样张：仓库内 5 张真实照片（`src-tauri/tests/fixtures/images/`），统一缩放到最长边 1400 px
- 方法：每个 Provider 先做 1 次冷启动调用，再对每张图做 3 次计时调用；质量探针为同图 3 次重复分析
- 声明：以下数字均为本机实测；没有标注集，因此**没有 NME**，不得把稳定性当成精度。

## 2. 耗时（ms）

| Provider | 冷启动（首次调用） | 热身后 min / p50 / max | 样本数 |
|---|---|---|---|
| Apple Vision | 313 | 59 / 63 / 95 | 15 |
| YuNet（debug） | 1527 | 1270 / 1278 / 1326 | 15 |

- 冷启动与单次推理分开记录，不混为一谈。
- Apple Vision 的 313 ms 包含 Vision 框架首次初始化；后续 59–95 ms（4 人合影最慢）。
- YuNet 在 debug 构建下约 1.28 s/张，主要是 tract 解释执行未优化；
  **release 构建下的数字未测量**，不得引用 debug 数字做发布承诺。
- 多人脸（4 人）比单人慢约 10–25 ms（Apple Vision）。

## 3. 重复分析稳定性（质量探针）

`probe_quality(portrait.jpg, runs=3)`：

| 项 | Apple Vision | YuNet |
|---|---|---|
| 是否适用 | 是 | 否（无稠密能力，直接返回不适用） |
| runs | 3 | 0 |
| 每轮人脸数 | 1 / 1 / 1 | — |
| 最大点位移（归一化） | 0.000000 | — |
| 眼距占比 | 0.000000（0%） | 1.000000（占位，表示不可信） |
| 耗时 | 30 / 28 / 30 ms | — |
| 结论 | verified=true | verified=false |

- 3 次完全一致说明在同一进程、同一图像上 Vision 结果是确定性的；
  这不等于跨设备、跨系统版本的稳定性，后者未验证。
- 探针门槛为 2% 眼距；实测 0.000%，远低于门槛。
- 若探针返回 0 张人脸，比值记为 1.0（100%）并在 `issues` 写明“无法计算眼距”，
  避免无穷大序列化成 `null` 让 UI 显示异常。

## 4. 置信度分布

| Provider | 样本 | min | p50 | p90 | max | <0.45 |
|---|---|---|---|---|---|---|
| Apple Vision | 24 | 1.000 | 1.000 | 1.000 | 1.000 | 0 |
| YuNet | 24 | 0.926 | 0.939 | 0.940 | 0.940 | 0 |

- Apple Vision 的数值是 `VNFaceObservation.confidence`，本机所有样张都饱和为 1.000；
  **它是人脸检测置信度，不是逐点置信度**。Vision 不提供逐点 confidence，
  代码把区域点的 confidence 设为同一个 observation 置信度，并在文档与 UI 中如实标注。
- 因此对 Apple Vision 而言，`min_confidence=0.45` 不构成有效筛选，门控主要依赖
  稳定性与结构检查。
- YuNet 的 score 分布在 0.926–0.940，波动小；同样没有逐点置信度。

## 5. 定位精度（NME）

| 指标 | 状态 |
|---|---|
| NME（68 点，相对眼距/瞳孔距离） | **未验证**：仓库没有带人工标注的关键点数据集，无法计算 |
| 眼睑贴合误差 | 未验证（同上） |
| 鼻翼/唇线边界误差 | 未验证（同上） |
| 侧脸 / 大角度 | 未验证：样张不含侧脸 |
| 遮挡（口罩/手/头发） | 未验证：样张不含遮挡 |
| 低照度 | 仅验证“能检出”（portrait_dark 1 脸 85 点），精度未测量 |
| 多人脸 | 已验证检出 4 张脸；逐脸精度未测 |
| 极端表情 | 未验证 |

结论：本轮能证明“稳定、可重复、点数和结构正确、能检出多人/明暗/高分辨率”，
**不能证明“定位误差小于 X%”**。要得到 NME，必须引入公开标注集（如 300W）
并写评测脚本，属于后续轮次。
