# LUMI RETOUCH

专业 AI 人像修图桌面应用。本地处理、无损对比、统一参数管线，面向摄影后期与影楼工作流。

- 技术栈：Tauri 2 + React 19 + TypeScript + Rust
- 版本：`0.1.0`（1.0 Beta）
- 平台：macOS（Apple Silicon 已验收）；Windows 未验证，暂不发布
- 项目文件：单文件 JSON（`.lumi`），不依赖数据库

---

## 功能概览

| 入口 | 说明 |
| --- | --- |
| **一键精修** | 自动检测人脸与皮肤分析，按「自然 / 标准 / 强力」三档生成修图计划；可整体调强度，参数仍可手动改，⌘Z 可撤销 |
| **手动调整** | 磨皮、五官塑形、基础影调、HSL、曲线等细粒度参数 |
| **导入 / 导出** | JPG / PNG / WebP / TIFF；单张导出与批量导出；原分辨率、预览与导出同一渲染管线 |
| **项目** | `.lumi` 保存参数、人脸锚点、蒙版与历史变更；可重开恢复 |
| **对比** | 分屏对比、按住看原图 |
| **批量处理 / RAW 显影** | 收在「文件」菜单（老用户入口）；当前 Beta **未开放 RAW 导入** |

支持格式：JPEG、PNG、WebP、TIFF（含 EXIF 方向、ICC 色彩管理）。  
RAW（CR2/CR3/NEF 等）会明确拒绝并提示，不会假装成功。

## 安装

### 方式一：安装已构建的 Beta 包（最终用户）

若你拿到的是 `LUMI RETOUCH_0.1.0_aarch64.dmg`（或同版本 `.app`）：

1. 打开 DMG，把 **LUMI RETOUCH.app** 拖到 **Applications**。
2. 首次启动：应用为 **ad-hoc 签名、未公证**，Gatekeeper 可能提示「无法验证开发者」。  
   在「系统设置 → 隐私与安全性」中点 **仍要打开**，或在 Finder 中右键应用 → **打开**。
3. 启动后应看到空状态「图库 00」「导入照片开始修图」。

命令行等价步骤：

```bash
hdiutil attach "LUMI RETOUCH_0.1.0_aarch64.dmg"
cp -R "/Volumes/LUMI RETOUCH/LUMI RETOUCH.app" /Applications/
open "/Applications/LUMI RETOUCH.app"
```

**卸载**：删除 `/Applications/LUMI RETOUCH.app` 即可（无后台服务、无数据库残留）。

### 方式二：从源码构建（开发者）

#### 环境要求

| 依赖 | 说明 |
| --- | --- |
| Node.js ≥ 20 + **pnpm** | 前端构建（仓库含 `pnpm-lock.yaml`） |
| Rust ≥ 1.87 + Cargo | 后端（`src-tauri`，`rust-version = "1.87"`） |
| macOS Xcode Command Line Tools | `xcode-select --install` |
| 平台 WebView | macOS 自带 WKWebView |

#### 步骤

```bash
# 1. 进入仓库
cd lumi人像   # 或你的本地目录名

# 2. 安装前端依赖
pnpm install

# 3. 开发模式（Vite 热更新 + Tauri 窗口）
pnpm app:dev

# 4. 生产构建（含默认 RAW feature 的完整包）
pnpm app:build

# 5. Beta 发行包（不含 LibRaw，与 1.0 Beta 一致）
pnpm app:build:beta
```

构建产物位置：

| 产物 | 路径 |
| --- | --- |
| `.app` | `src-tauri/target/release/bundle/macos/LUMI RETOUCH.app` |
| `.dmg` | `src-tauri/target/release/bundle/dmg/LUMI RETOUCH_*.dmg` |

> **关于 RAW / LibRaw**  
> 默认构建（`pnpm app:build`）会链接 LibRaw，仅限**内部开发与自用**，对外分发前须完成 LGPL 合规审核。  
> 对外 Beta 一律使用 `pnpm app:build:beta`（`--no-default-features`），包内无 LibRaw 符号。

#### 常用开发命令

```bash
pnpm dev          # 仅前端 Vite
pnpm build        # tsc 类型检查 + vite build
pnpm typecheck    # 仅类型检查
pnpm test         # vitest 单测（前端）
pnpm test:watch   # 单测 watch
```

Rust 测试：

```bash
cd src-tauri
cargo test
```

## 使用教程

### 1. 导入照片

任选其一：

- 顶栏 **导入**，或菜单 **文件 → 导入照片…**（`⌘O`）
- 把照片拖进窗口
- 空状态点击「选择照片」

可多选；重复路径会自动去重。损坏文件、不支持扩展名、RAW 会弹出明确错误，图库不增加条目。

### 2. 一键精修（推荐首次使用）

1. 导入后切换到顶栏 **一键精修**。
2. 面板会自动做人脸检测与皮肤分析（首次略等进度）。
3. 选择档位：**自然 / 标准 / 强力**，拖动 **整体强度**。
4. 点击应用 → 参数一次性写入，可用 **对比** 左右检查。
5. 不满意：**撤销**（`⌘Z`）或 **重新精修**；已手动改过的项在重新精修时会尽量保留。

> 一键结果不是「黑盒锁死」：应用后仍可在 **手动调整** 里逐项改，再 `⌘Z` 回退。

### 3. 手动调整

切换到 **手动调整**，常用分区：

| 分区 | 典型参数 |
| --- | --- |
| 磨皮美肤 | 磨皮、质感、细节、祛痘、肤色均匀、提亮、去红等 |
| 五官塑形 | 整体瘦脸、左右脸、下颌、颧骨、宽高与平衡（轮廓级） |
| 基础影调 | 曝光、对比度、高光、阴影、白平衡、色温、色调、饱和度 |
| 色彩 | HSL 八通道、曲线、锐化、降噪、暗角 |

操作技巧：

- 每项拉回 **0** 即恢复该项原状。
- 按住 **`\`** 可临时查看原图。
- **复制参数** `⌥⌘C` / **粘贴参数** `⌥⌘V` 可套用到另一张照片。
- **编辑 → 重置全部参数** 清空当前照片所有调整。

### 4. 保存项目

- **文件 → 保存项目…**（`⌘S`）：首次选择路径，生成 `.lumi` 文件。
- 项目内含：照片引用、全部参数、人脸锚点、蒙版、导出设置等。
- **没有自动保存**。状态栏有「未保存」提示；关窗或 `⌘Q` 时若未保存会弹出确认（系统对话框按钮为英文 Yes/No）。
- **没有「另存为」**：`⌘S` 覆盖当前项目；需要副本请在 Finder 中复制 `.lumi` 再打开。

### 5. 打开项目

- **文件 → 打开项目…**（`⇧⌘O`，注意不是 `⌘O`）。
- 旧版本项目打开时若结构有差异，会走迁移并提示；参数应完整恢复。
- 源照片缺失时按「缺失源」流程提示，不会静默丢参数。

### 6. 导出

- **文件 → 导出当前照片…**（`⌘E`）。
- 格式：JPEG / PNG / WebP（可调质量）；PNG/TIFF 嵌 ICC 时为 16-bit，JPEG 为 8-bit。
- 单张按**原分辨率**导出，不缩放。
- 批量：**文件 → 批量处理…**，支持失败重试与覆盖确认。

### 7. 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `⌘O` | 导入照片 |
| `⇧⌘O` | 打开项目 |
| `⌘S` | 保存项目 |
| `⌘E` | 导出当前照片 |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做 |
| `⌥⌘C` / `⌥⌘V` | 复制 / 粘贴参数 |
| `\`（按住） | 临时看原图 |
| `F` | 适应窗口 |
| `1` | 实际像素（100%） |
| `2` | 放大到 200% |
| `⌘\` | 分屏对比（菜单标注；以实际绑定为准） |

> 注意：`⌘O` 是**导入**，打开项目是 `⇧⌘O`。该键位已在发行说明中记录，与部分软件习惯不同。

### 8. 推荐工作流（一张样张）

```
导入照片
  → 一键精修（选档 + 强度）→ 对比检查
  → 手动微调磨皮 / 瘦脸 / 曝光
  → ⌘S 保存项目
  → ⌘E 导出
  → 需要下一组：继续导入或「批量处理」
```

## 已知限制（1.0 Beta）

1. **RAW 导入未开放**（LibRaw 许可审核中）；导入 RAW 会明确报错。
2. **未签名公证**：首次打开需右键「打开」或在系统设置中放行。
3. **Windows 未验证**，不随 Beta 发布。
4. **无自动保存**；崩溃前未 `⌘S` 的修改会丢失。
5. 人物分割为**手动蒙版**，皮肤分割为几何蒙版；不宣称 AI 语义抠图。
6. 稠密五官关键点（LEVEL 3）保持锁定，界面只提供 5 点几何锚点能力。
7. 无独立「新建项目」：导入照片即开始新项目。
