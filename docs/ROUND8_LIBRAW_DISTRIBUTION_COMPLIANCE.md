# ROUND 8 — LibRaw / LGPL 分发合规

- 日期：2026-11-21
- 对象：`libraw_rs_vendor 1.0.0`（内置 LibRaw 0.21.1），静态链接进 macOS 应用
- 状态：**未完成发行合规打包**。本轮不发布对外版本，因此没有把“已合规”写进任何材料。
- 第八轮没有升级/修改 LibRaw，也没有新增任何 RAW 相关依赖。

## 1. 许可事实

| 项 | 内容 |
|---|---|
| LibRaw 许可证 | LGPL-2.1-only **或** CDDL-1.0（双许可，由使用方选择） |
| 本项目选择 | 按 LGPL-2.1 遵守（静态链接） |
| Rust 绑定 | `libraw_rs_vendor`，包装层按其仓库声明 |
| 使用范围 | 文件识别、`unpack` 原始像素、元数据、内嵌预览；不调用 `dcraw_process` |
| 本地修改 | 当前仅通过编译选项启用/关闭功能，未修改 LibRaw 源码；若未来修改必须在文档登记 |
| 链接方式 | 静态库编进 `lumi-retouch` 可执行文件（release 包 15.85 MiB） |

## 2. LGPL-2.1 静态链接义务（逐项）

| # | 义务 | 当前状态 | 发行前动作 |
|---|---|---|---|
| 1 | 提供 LibRaw 完整对应源码（含修改） | 仓库只有 Cargo 依赖与 `Cargo.lock`，未附源码包 | 在 `bundle.resources` 或发行附件放入 `LibRaw-0.21.1.tar.gz` |
| 2 | 提供构建脚本与编译选项，使第三方可复现 | 未提供 | 附 `libraw-build.sh` 与 `cargo build` 版本/特性说明 |
| 3 | 允许用户用修改后的 LibRaw 重新链接 | 未提供目标文件或重链接步骤 | 提供 `.o`/`.a` 或详细重链接说明（含链接顺序与系统框架） |
| 4 | 保留版权声明与许可证文本 | `THIRD_PARTY_LICENSES.md` 已登记；包内无独立 LICENSE 附件 | 在应用“关于/第三方许可”与安装包内加入 LGPL-2.1 原文与 LibRaw 版权 |
| 5 | 不限制反向工程以调试修改后的库 | 无相关限制条款 | 确认 EULA 不含冲突条款 |
| 6 | 修改声明 | 当前无修改 | 若修改，发布补丁与说明 |

## 3. 与 Apple Vision / 商业 SDK 的边界

- Apple Vision 是系统框架，不打包其二进制，不涉及 LGPL。
- 本轮**没有**引入 Banuba / NVIDIA Maxine，因此不存在其商业许可的分发义务。
- 用户自备 ONNX 模型不进入安装包，不改变 LibRaw 义务。

## 4. CDDL-1.0 备选路径（未采用）

CDDL-1.0 允许以文件为单位的弱 copyleft，可避免静态链接的“重链接”义务，
但需要按 CDDL 提供 LibRaw 源码与修改说明，且与 LGPL 的兼容性需法务确认。
当前不切换到 CDDL，保持 LGPL-2.1 路径。

## 5. 结论

1. 本轮代码不改变 LibRaw 集成方式，不新增合规风险。
2. **发行合规仍未完成**：第 2 节 6 项中仅第 4 项的登记部分完成，源码/构建/重链接附件缺失。
3. 在补齐上述附件前，不得对外宣称“LGPL 合规”或发布含 LibRaw 的正式安装包。
4. 建议下一轮把“第三方许可页面 + LibRaw 源码包 + 重链接说明”纳入打包检查清单。
