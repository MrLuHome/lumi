## 2. 本轮改动

### 2.1 未保存状态

- `editorStore` 新增 `unsaved` 与 `setUnsaved`。
- 导入、参数、蒙版、人脸记录、导出/色彩设置、计算偏好等会被写入项目的引用发生变化时置为 `true`；
  保存成功、打开项目、关闭项目时置为 `false`。
- 右下角项目指示变为：
  - `项目：xxx.lumi`（已保存）
  - `项目：xxx.lumi · 未保存` / `未命名项目 · 未保存`（有修改）
- 恢复期（`loadSession.phase === "restoring"`）不标记，避免打开项目后立刻显示未保存。

### 2.2 关闭保护

- Rust 新增 `UnsavedGuard`（`AtomicBool`）与命令 `set_unsaved_changes`。
- 主窗口 `CloseRequested`：有修改时 `prevent_close()`，弹出原生确认；选择 Yes 才真正关闭。
- `RunEvent::ExitRequested`：覆盖 ⌘Q / 系统退出路径；`code` 为空的退出同样先确认。
- 确认文案：「有尚未保存的修改，退出后本次修改会丢失。仍要退出吗？」
- 保存成功后会同步 `dirty=false`，因此保存后关闭不再打扰。

## 3. 已知限制

1. 没有自动保存；依赖「未保存」提示 + 关窗确认。Beta 发行说明需明确。
2. 没有可视化历史时间线，只有撤销/重做。
3. 没有独立「新建项目」入口；导入第一张照片即为新项目。
4. 单张导出只有完成提示，没有进度条；耗时通常低于 1.5 s。
5. 关闭确认框按钮文案跟随系统（英文 Yes/No）。
6. 身材/背景本轮未做新的 GUI 逐步截图，列入阶段 F 的全量验收补测。

## 4. 未改动的部分

- 没有为 UI 美观压缩画布；新增元素只是右下角 9px 状态文字与原生确认框。
- 没有改动既有快捷键映射与参数面板布局。
- 没有新增网络请求、遥测或账号体系。
